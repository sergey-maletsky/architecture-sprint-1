# Задание 1. Mesto. Переход на микрофронтенды

## 1. Анализ
это небольшое приложение по созданию "фотографической истории" пользователя по посещенным местам 
или можно интерпретировать просто как хранилище изображений. 
в этом проекте есть смысл продолжать разрабатывать на ReactJS во всех микрофронтендах, 
которые будут созданы в дальнейшем т.к. нет смысла для такого небольшого проекта усложнять его 
технологически. по крайней мере сейчас в этом смысла нет. 

## 2. Определить бизнес-функции
Выбираю стратегию вертикальной нарезки тк считаю, что необходимо организовать 
микрофронтенды вокруг бизнес-возможностей
Руководствуясь принципами DDD, выделил модули микрофронтендов:
#### 1. Авторизация/регистрация
#### 2. Карточки фотографий
#### 3. Профиль пользователя

## 3. Техническая реализация микрофронтендов
### Выбор инструментов для создания микрофронтендов
Для создания микрофронтендов буду использовать фреймворк Module Federation
тк он хорошо зарекомендовал себя в различных проектах и отлично подходит,
если не нужна интеграция с микросервисами, написанных на различных фреймворках, 
а в п.1. мы решили продолжать разработку на ReactJS во всех микрофронтендах

### Декомпозиция
Микрофронтенды здесь хорошо делятся по имеющимся бизнес-функциям т.е.
#### 1. Авторизация/регистрация ложится на auth-microfrontend
Сюда я переношу компоненты: Header, InfoTooltip, Login, Register т.к. они напрямую связаны 
с функциями авторизации и регистрации
#### 2. Карточки фотографий ложится на cards-microfrontend
Сюда я переношу компоненты: PopupWithForm, AddPlacePopup, Card, ImagePopup, Main т.к. они напрямую связаны
с функциями добавления карточки, редактирования и удаления.
#### 3. Профиль пользователя ложится на profile-microfrontend
Сюда я переношу компоненты: EditAvatarPopup, EditProfilePopup, PopupWithForm т.к. они напрямую связаны
с функциями работы с профилем
#### 4. host-microfrontend - основной компонент в роли оркестратора, связывающий все остальные компоненты в концепции MDA. В нем находятся все базовые элементы и компоненты всего приложения
Сюда я переношу компоненты: Footer, ProtectedRoute
также здесь общие стили, изображения и базовая структура и рендеринг приложения в App.jsx
